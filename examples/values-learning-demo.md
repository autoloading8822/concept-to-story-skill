# Values learning demo / 把价值冲突变成看得见的场景

这是五个独立的原创教学示例，方便浏览与评估；真实教学每次只展示一个知识点并等待回答。

**来源说明：没有提供书籍 PDF。** 下文各段“教学前提”是本项目为演示而写的合成说明，不是任何作者的原文或立场，也不是哲学、心理学文献综述。故事、人物和情节均为虚构。“大象与骑手”“无知之幕”等已有概念或比喻不被宣称为本项目原创；这里不把它们归属于未读取的书。框架存在边界，不能由故事判断一个人的全部价值观。

## Knowledge Point 1 — Moral intuition / 先有判断，再找理由

### Source

**SOURCE: synthetic teaching premise** — 本示例的教学前提：某些判断可能先出现直觉反应，之后才组织理由；这不表示每次判断都如此，也不表示理性永远无效。没有 PDF 页码。

### Core Idea

有时我们先觉得一件事“不对”，随后才找出能说出口的理由。判断出现得快，不代表理由已经被认真检查。

### Why It Matters

当争论中一个理由被推翻、立场却完全不动时，你会想到检查最初反应，而不只是继续堆理由。

### Story

**SUPPLEMENTARY EXPLANATION — 原创虚构场景。**

周五聚餐，小林听说好友没有参加同事的募捐，脱口而出：“他太冷漠了。”她希望大家都照顾有困难的人，也想维护自己对好友的信任。有人提醒她，好友可能已经私下捐款。小林没核实，就改口说：“那也应该公开表态。”另一位同事问，如果他不愿公开自己的捐款记录呢？她发现自己在不断更换理由，却没有重新检查最初的结论。她得在当场保住面子和弄清情况之间选择。最后她说：“我刚才下判断太快了，我还不知道他做了什么。”她暂时收回评价，准备先问清事实。最初的不舒服还在，但不再直接决定她说出口的话。

### Memory Anchor

🧠 Memory Anchor: 一头先迈步的大象，背上的骑手正在解释路线。

### Back to the Theory

小林的第一反应对应直觉判断；保护他人和维护既有评价构成冲突；不断换理由对应事后辩护；暂停评价的选择显示反思仍可能修正表达与判断。大象与骑手是借用的已有教学比喻，故事是原创。

### Where the Analogy Breaks

不能从这个场景推出所有理由都是借口，或人不能靠证据改变判断。现实中也不能仅凭某人说话很快就断定其心理过程。

### Real-Life Signal

观察一个理由被新证据削弱后，对方是否愿意调整结论，还是不断换理由而不检查事实；这只是进一步询问的线索。

### Active Recall

一位主管先认定远程工作的员工偷懒，看到产出记录后又改说“不来办公室就是态度有问题”。你会用什么问题区分他是在评估证据，还是维护先前判断？

## Knowledge Point 2 — Fairness / Reciprocity / 帮助是否有回来的方向

### Source

**SOURCE: synthetic teaching premise** — 互惠分析关注长期互动中帮助与成本是否可能双向流动，同时考虑能力和需要差异。它只是讨论公平的一种角度，不等于全部公平理论。没有 PDF 页码。

### Core Idea

判断一段互助关系，可以看看帮助换一个方向时，对方是否也愿意承担合理成本。互惠不要求每次帮助都等价偿还。

### Why It Matters

你可以把“他到底有没有价值观”换成一个可以核对的关系问题，而不是用一个总标签代替分析。

### Story

**SUPPLEMENTARY EXPLANATION — 原创虚构场景。**

阿哲三次找阿宁帮忙：搬家、凌晨接机、周末整理 Excel。阿宁都尽量配合，因为她想维持这段友情。后来她搬家，需要有人搭把手，阿哲说太累；她改约下周，他又说想休息。阿宁没有立刻翻出账本要求“还三次”，而是问他哪天方便，只需一小时。阿哲承认最近并没有特别困难，只是不想牺牲自己的周末，却继续催她帮自己改表格。阿宁必须在维持随叫随到的习惯和保护自己的时间之间选择。她拒绝了这次临时改表的请求，提出以后提前约、双方都可以拒绝。阿哲失去了默认的随时服务，两人也终于需要讨论帮助的边界。

### Memory Anchor

🧠 Memory Anchor: 两根方向相反的箭头，其中一根被堵住。

### Back to the Theory

两位朋友是长期互动者；双方时间都有限构成成本冲突；阿宁改变默认答应的选择，使帮助方向的不对称显现。箭头表示愿意互相承担成本，不是次数账本。

### Where the Analogy Breaks

长期照护、疾病或能力差异可能让帮助合理地不对称。一次拒绝不能证明缺乏互惠，也不能把所有友情变成严格交换。

### Real-Life Signal

帮助方向反转时，对方是否愿意解释限制、寻找可行时间或提供能力范围内的其他帮助？结合长期模式和实际负担判断。

### Active Recall

一位朋友因长期照顾家人不能接送你，却愿意花时间帮你联系可靠的司机。只按“有没有亲自接送”判断互惠，会漏掉什么？

## Knowledge Point 3 — Autonomy / Liberty / 空闲不等于授权

### Source

**SOURCE: synthetic teaching premise** — 此处用一个简化的自主框架区分资源暂未使用与所有者同意他人控制该资源。它不代表法律意见，也不涵盖所有自由理论。没有 PDF 页码。

### Core Idea

你暂时不用某项资源，不等于别人因此获得决定如何使用它的权力。需要与同意是不同的问题。

### Why It Matters

你会听出“反正你用不上”可能跳过了哪一步：真正得到拥有者的许可。

### Story

**SUPPLEMENTARY EXPLANATION — 原创虚构场景。**

周六早上，阿远想借小夏的车去郊外，看到车钥匙放在玄关，就说：“你今天在家，这车空着也是空着。”小夏想帮朋友，也担心车上的设备和晚上的临时出行。她说今天不借，但可以一起查租车。阿远觉得租车要花钱，伸手拿起钥匙，说回来加满油就行。小夏此时必须在避免尴尬和坚持自己作决定之间选择。她把钥匙收回，明确说明，加油能补偿油费，却不能替她作出是否出借的决定。阿远最后自己安排了交通。车依旧停在楼下，但双方知道，停着的车不是默认向任何人开放的资源。

### Memory Anchor

🧠 Memory Anchor: 一扇关着的门，钥匙仍在主人手里。

### Back to the Theory

小夏对应有权作决定的人；阿远的便利需求与她的控制权冲突；收回钥匙对应保留许可权；改用其他交通说明需求可以另找途径，而不是自动转化为授权。

### Where the Analogy Breaks

这个日常借车情境没有处理紧急救助、共同所有权或事先约定等情况。不能据此推出资源拥有者在任何情况下都不承担义务。

### Real-Life Signal

当你明确拒绝后，对方是继续协商替代方案，还是把自己的需要当成已经获得的许可？

### Active Recall

室友发现你的房间空着，没问你就让来访朋友住进去，并承诺打扫干净。打扫承诺解决了什么，又没有解决什么？

## Knowledge Point 4 — Veil of Ignorance / 先定规则，再知道自己的位置

### Source

**SOURCE: synthetic teaching premise** — 此处用一个简化的公平思想实验：设计规则时暂时不知道自己的社会位置，以减少针对自身优势制定规则的偏向。不是对任何哲学家完整论证的转述。没有 PDF 页码。

### Core Idea

设想你还不知道自己将处于哪种位置，再判断愿意接受什么规则。它让你检查规则是否只对当前的自己有利。

### Why It Matters

你可以发现，一个看似中立的规则，是否偷偷假定每个人都和你有相同的起点。

### Story

**SUPPLEMENTARY EXPLANATION — 原创虚构场景。**

阿珊在一个思想实验里进入黑房间，面前只有一张社会规则表和一个随机出生按钮。她要先决定学校怎样分配基础学习资源，再按按钮得知自己的家庭与身体条件。起初她想把最好资源留给能付高额费用的人，因为她习惯了家里替自己买课程。屏幕提醒她，下一次可能出生在完全付不起费用的家庭，也可能需要额外的学习支持。她想保留个人选择，又不愿让起点差异直接取消某些人的学习机会。最后她选择保障基础支持，再允许额外选择，并写下需要进一步比较的成本。按钮尚未按下，她已经不能再用“我家付得起”作为人人适用的理由。

### Memory Anchor

🧠 Memory Anchor: 黑房间里一个尚未按下的随机出生按钮。

### Back to the Theory

阿珊是规则制定者；个人习惯与未知位置构成冲突；先写规则再揭示身份的顺序阻断直接按自身优势设计规则；重新说明理由展示了视角变化。

### Where the Analogy Breaks

黑房间和按钮只是视觉简化，不是在主张真实的出生抽签机制。它没有单独证明唯一正确的分配制度，选择仍需要进一步论证。

### Real-Life Signal

评价一条制度时，换一个可能受影响的位置，检查原先的理由是否仍成立，尤其关注规则假定了哪些起点条件。

### Active Recall

团队规定所有紧急会议都在晚上召开。如果制定规则时不知道自己会是单身员工、照护者还是跨时区同事，你会重新检查哪项隐藏假设？

## Knowledge Point 5 — Special Obligations / 关系带来额外理由，不是无限索取

### Source

**SOURCE: synthetic teaching premise** — [原创测试文本第 5 节](../tests/fixtures/learning-source.md#5-special-obligations)：一种关系义务框架认为，特定关系可以提供额外帮助理由，但不自动压倒所有其他承诺、成本与同意。没有 PDF 页码。

### Core Idea

关系可以让你有更多理由帮助某个人，但这不表示对方的每个要求都必须满足。关系义务也不等于严格的互惠记账。

### Why It Matters

你能同时理解“我愿意多帮朋友”和“我可以拒绝这次要求”，而不必把它们当成矛盾。

### Story

**SUPPLEMENTARY EXPLANATION — 原创虚构场景。**

阿禾准备职业考试，好友小江正在开店。小江请她周末帮着布置，她留出半天，因为这段友情让她愿意比对陌生人多承担一些。到了店里，小江又安排她下周盘货、下下周看店，说：“咱们这么熟，你肯定会帮到底。”阿禾想支持朋友，也不想放弃自己的考试计划。她面临的选择不是要不要这段友情，而是这次帮助能延伸到哪里。她告诉小江，今天约好的半天会做完，之后只能偶尔提前商量，不能默认排班。小江需要重新找人，但阿禾没有撤回友情。她只是把一张有额外权益的朋友会员卡，放回了它并非无限信用卡的位置。

### Memory Anchor

🧠 Memory Anchor: 朋友会员卡 ≠ 无限信用卡。

### Back to the Theory

好友关系提供额外帮助理由；开店需要与考试承诺构成冲突；履行已答应的半天、拒绝无限延伸体现有边界的关系义务；重新找人说明额外理由不自动形成无限权利。

### Where the Analogy Breaks

友情不是商业会员合同，义务大小也没有统一额度。紧急程度、既有承诺、能力和负担会改变具体判断；这只是一个规范框架。

### Real-Life Signal

当你说明其他承诺和可承担的范围时，对方是否愿意讨论这次请求，而不是仅凭“我们是朋友”要求你接受所有安排？

### Active Recall

一位好友突然需要紧急照护，另一位只是临时想让你陪逛街。即使你和两人同样亲近，为什么不能只凭同一张“会员卡”决定应承担多少帮助？
